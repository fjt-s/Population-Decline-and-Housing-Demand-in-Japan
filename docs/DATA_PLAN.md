# データ取得計画

## 構成

```
scripts/
  estat_client.py        e-Stat API 3.0 の薄いラッパー（getStatsList / getStatsData）
  reinfolib_client.py     不動産情報ライブラリ API の薄いラッパー（XYZタイル対応）
  fetch_census.py         国勢調査（人口・世帯数）取得スクリプト
  fetch_housing_starts.py 住宅着工件数 取得スクリプト
  fetch_land_price.py     公示地価・地価調査 取得スクリプト
data/
  raw/                    API から取得した生データ（gitignore対象）
  processed/              集計・整形後のデータ（gitignore対象）
  external/               手動ダウンロードした補助データなど（gitignore対象）
.env.example              ESTAT_APP_ID / REINFOLIB_API_KEY のテンプレート
```

APIキー発行後は `.env.example` を `.env` にコピーし、値を入れて `pip install -r requirements.txt`。

## 各データソースの詳細

### 1. 国勢調査（人口・世帯数）— ✅ 取得済み

- API: e-Stat API（`getStatsList` / `getStatsData`）
- 政府統計コード: `00200521`
- 対象年: 2000, 2005, 2010, 2015, 2020（2025年国勢調査は結果公表後に追加）
- 地域粒度: 市区町村コード（5桁, `@area`）単位で人口・世帯数・5年間の増減率・面積・人口密度が取得可能
- 統計表ID（年ごと、`fetch_census.py` の `CENSUS_TABLES` に固定済み）:
  | 年 | statsDataId |
  |---|---|
  | 2000 | 0003391075 |
  | 2005 | 0003408216 |
  | 2010 | 0003411171 |
  | 2015 | 0003148500 |
  | 2020 | 0003433220 |
- `python scripts/fetch_census.py fetch-all` で5年分を `data/raw/census_<year>_<id>.json` に保存済み（各10〜14MB）

### 2. 住宅着工件数 — ✅ 取得済み（ただし要注意点あり）

- API: e-Stat API（同上）
- 政府統計コード: `00600120`（建築着工統計調査）
- **「建築物着工統計 表7-2」を使用**（市区町村別、用途別（大分類）／建築物の数・床面積・工事費予定額）
  - 「住宅着工統計」本体の確報（新設住宅着工戸数）は都道府県別までしか出ないため使えない。
  - `cat01`（用途）のうち住宅系は `12`（居住専用住宅）`13`（居住専用準住宅）`14`（居住産業併用建築物）。
    これらを合算したものを「住宅着工件数」の近似値として使う（新設住宅着工戸数とは定義が異なる点に注意）。
  - 統計表ID:
    | キー | statsDataId | 対象年 |
    |---|---|---|
    | calendar_2011_2019 | 0003114492 | 2011〜2019年（暦年） |
    | fiscal_2020_2023 | 0004019381 | 2020〜2023年度 |
    | (参考) fiscal_2011_2019 | 0003117502 | 2011〜2019年度 |
  - `python scripts/fetch_housing_starts.py fetch-all` で `data/raw/housing_starts_*.json` に保存済み
- **⚠️ 2つの重要な制約**:
  1. **市区町村別データは2011年分以降のみ**。国勢調査は2000年から取れるが、住宅着工の市区町村別は
     2011年が下限（2000〜2010年は e-Stat 上に存在しない）。
  2. **2020年に集計基準が「暦年」→「年度」に切り替わっている**（建築基準法別表改正に伴う区分変更）。
     2011-2019と2020以降を単純に結合する際はこの切り替わりに注意する。

### 3. 公示地価・地価調査

- API: 不動産情報ライブラリ API。全国取得には **`XCT001`（鑑定評価書情報API）を採用**（決定）。
  - 都道府県コード（`area`, 01〜47）指定の非タイル方式なので、47都道府県をループするだけで全国を
    網羅でき、`XPT002`（XYZタイル方式）で全国を走査する場合（数十万タイル規模）に比べて現実的。
  - `division`（用途区分）は住宅需要分析の主眼に合わせて `00`（住宅地）をデフォルトにする。
  - レスポンスに都道府県コード・市区町村コード・緯度経度・㎡単価などが含まれ、市区町村単位への
    集計はこの後の前処理で行う。
  - **⚠️ 年の制約**: `year` は 2022〜2026年のみ指定可能（2026年8月時点のAPI仕様）。国勢調査
    （2000〜2020年、5年おき）と同じ年での突合ができない。直近の地価水準として横断的に使うか、
    より長い時系列が要る場合は `XPT002`（1995〜2024年、タイル方式）で対象都道府県だけ補完取得する
    運用にする（`reinfolib_client.get_land_price_tile` / `tiles_for_bbox` を参照）。

## 決定事項

- **地域粒度**: 市区町村単位 → 住宅着工は「建築物着工統計 表7-2」を使用
- **対象地域**: 全国（仮説検証・外れ値探索のため地域を絞らない）→ 地価は `XCT001` を都道府県ループで取得
