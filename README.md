# Population Decline and Housing Demand in Japan

## Motivation

石川への帰省時に、人口減少地域であっても新築戸建て住宅が数多く建設されていることに疑問を持った。

本分析では、人口減少下でも住宅着工が維持される地域の特徴を明らかにすることを目的とする。

## Research Question

人口減少率だけで住宅着工件数を説明できるのか？

## Hypotheses

- 核家族化の進展に伴う世帯数増加が関係している
- 地価が関係している
- 都市圏へのアクセスが関係している

## Data Sources

- e-Stat
- 国勢調査
- 住宅着工統計
- 公示地価
- 住宅・土地統計調査（持ち家/借家比率、通勤時間中位数）

## Findings（暫定）

- 人口減少率と住宅着工率の相関は、自治体を**人口密度**で区分すると強さが変わる。高密度都市部
  （4,000人/km²以上）では延床面積ベースの相関が r≈0.70 と強いのに対し、農山村・過疎的な自治体
  （300人/km²未満）では r≈0.36 まで弱まる（`scripts/analyze.py` 案1-b/c）。
- 密度・持ち家率・通勤時間（都市圏アクセスの代理指標）・地価を1つの回帰モデルにまとめ、頑健標準誤差
  ＋対数変換DVでの頑健性確認まで行った（案1-i、Statistical Modeling段階）。結果:
  - **持ち家率（戸建て信仰）が最も頑健な説明変数**。密度を統制してもp=0.005で有意、DVを対数変換
    しても有意性が保たれる（p=0.011）。地方ほど持ち家率は高く（log人口密度との相関 r≈-0.64、
    高密度都市部54%→農山村79%）、持ち家率が高い自治体ほど人口変化が着工率に与える影響は弱まる。
    地方の住宅着工は人口動態に応じた需給調整より、持ち家取得というライフイベントに駆動されている
    可能性を示唆する。
  - **地価は独立の説明力を持たない**。密度を統制すると交互作用は非有意（p=0.069）、地価だけで
    区分し直しても同じ傾向は再現されない（案1-d/e）。密度とほぼ同じ情報（VIF≈5.5）を持つため、
    統合モデルに加えても追加のフィットはわずか（ΔAIC 5→改善はF検定でp=0.010とギリギリ有意）。
  - **通勤時間（都市圏アクセス）は生データでは有意（p=0.030）だが頑健ではない**。DVを対数変換
    すると交互作用は非有意化する（p=0.272）ため、raw DVの歪み（歪度4超）に引きずられた見かけの
    効果である可能性が高い。README仮説の「都市圏へのアクセス」は現時点では支持材料が弱い。
